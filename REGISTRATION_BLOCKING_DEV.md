# Trainee registration enforcement — development

Use the existing `PARENT_REGISTRATION_ENABLED=true` and
`PARENT_REGISTRATION_BLOCKING_ENABLED=true` Server flags, with
`VITE_PARENT_REGISTRATION_ENABLED=true` and
`VITE_PARENT_REGISTRATION_BLOCKING_ENABLED=true` on the Client.
Keep existing database identity/TLS attestation and `DB_SYNC=false`,
`DB_LOGGING=false`. No migration or new flag is needed.

The prepared local registration launcher (`scripts/phase5-local.cjs`) already
sets both Server and Client blocking flags and matching loopback API origins.
Use its existing protected configuration; do not copy Production credentials
into local configuration. Do not run its fixture/setup actions against a shared
database just to enable blocking.

For a subsequent authorized Railway DEV rollout, set these flags on the DEV
services only. Preserve the exact DEV API URL and Client environment `dev`.
The Vite flags require a Client rebuild. Server changes require a restart or
deployment. This local implementation does not change Railway variables or
deploy either service. Production/main remain unchanged.

Blocking applies to trainee-only accounts when an annual branch period requires
registration or an individual request has `blocksAccess=true`. It does not open
periods or create requests. Existing intentionally nonblocking individual
requests remain nonblocking. Managers and volunteers, including mixed-role
accounts, are excluded.

`DRAFT`, `PENDING_REVIEW` and `CHANGES_REQUESTED` remain restricted. Protected
API requests check live database state, rather than JWT-cached approval. Only
existing explicit registration/authentication/profile-read essentials are
exempt. Approval removes the requirement; the Client automatically checks at
15-second intervals. Pending review forms follow manager decisions every three
seconds and remount from the saved server revision when returned for correction.
Editable drafts and signatures are never periodically replaced.

Status failures fail closed. Access can be retried without signing out.
